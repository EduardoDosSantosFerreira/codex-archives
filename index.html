Comandos CMD/PowerShell

Gerenciamento do Sistema

Desempenho do Sistema

powercfg.exe /hibernate off # Desativa hibernação para liberar espaço
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61 # Esquema Ultimate Performance
wpr -cancel # Para rastreamentos de desempenho em execução

Atualizações e Pacotes

winget upgrade --all # Atualiza todos os pacotes instalados
choco upgrade all # Atualiza todos os pacotes Chocolatey
sfc /scannow # Verifica e repara arquivos do sistema

Rede e Conectividade

Diagnóstico de Rede

ipconfig /all # Mostra toda configuração de rede
netsh wlan show profiles # Lista redes Wi-Fi salvas
ping google.com -t # Ping contínuo (Ctrl+C para parar)
tracert 8.8.8.8 # Rastreia rota até o destino

Gerenciamento de Rede

netsh interface ip show config # Mostra configurações IP
netsh winsock reset # Reseta catálogo Winsock
netstat -ano # Mostra conexões e ports abertos
nslookup example.com # Consulta DNS

Arquivos e Discos

Operações com Arquivos

robocopy C:\origem D:\destino /MIR /NP /LOG:log.txt # Cópia avançada
del /S /Q *.tmp # Remove todos arquivos .tmp
tree /F /A > arvore.txt # Gera árvore de diretórios

Gerenciamento de Disco

chkdsk /f /r C: # Verifica e repara disco
defrag C: /U /V # Desfragmenta disco com relatório
fsutil file createnew grande_arquivo.txt 1073741824 # Cria arquivo de 1GB

Processos e Serviços

Gerenciamento de Processos

tasklist /svc # Lista processos e serviços
taskkill /IM chrome.exe /F # Força fechamento do Chrome
wmic process get name,processid,commandline # Lista detalhada de processos

Controle de Serviços

sc queryex type= service state= all # Lista todos serviços
net start # Lista serviços em execução
sc config "servicename" start= delayed-auto # Configura serviço

Utilitários Avançados

Informações do Sistema

systeminfo # Detalhes completos do sistema
wmic bios get serialnumber # Número de série da BIOS
powercfg /energy # Diagnóstico de energia

Comandos Úteis Diversos

shutdown /r /t 0 # Reinicia o PC imediatamente
cipher /w:C # Sobrescreve espaço livre no disco
whoami /all # Mostra informações do usuário atual

Comandos PowerShell

Administração do Sistema

Get-WindowsUpdateLog # Log de atualizações
Get-Process | Sort-Object CPU -Descending # Processos por uso CPU
Get-NetTCPConnection -State Established # Conexões ativas

Utilitários PowerShell

Get-ChildItem -Recurse | Measure-Object -Property Length -Sum # Tamanho total de arquivos
Test-NetConnection google.com -Port 80 # Testa porta específica
Get-HotFix | Sort-Object InstalledOn -Descending # Updates instalados
