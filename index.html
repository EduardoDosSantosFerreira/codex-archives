Comandos CMD/PowerShell

Gerenciamento do Sistema

Desempenho do Sistema

powercfg.exe /hibernate off # Desativa hibernação
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61 # Ultimate Performance
wpr -cancel # Para rastreamentos

Atualizações e Pacotes

winget upgrade --all # Atualiza todos os pacotes
choco upgrade all # Atualiza Chocolatey
sfc /scannow # Verifica arquivos do sistema

Rede e Conectividade

Diagnóstico de Rede

ipconfig /all # Mostra configurações de rede
netsh wlan show profiles # Lista Wi-Fi salvas
ping google.com -t # Ping contínuo
tracert 8.8.8.8 # Rastreia rota

Gerenciamento de Rede

netsh interface ip show config # Mostra IP
netsh winsock reset # Reseta Winsock
netstat -ano # Mostra conexões ativas
nslookup example.com # Consulta DNS

Arquivos e Discos

Operações com Arquivos

robocopy C:\origem D:\destino /MIR /NP /LOG:log.txt # Cópia avançada
del /S /Q *.tmp # Remove arquivos .tmp
tree /F /A > arvore.txt # Gera árvore de diretórios

Gerenciamento de Disco

chkdsk /f /r C: # Verifica e repara disco
defrag C: /U /V # Desfragmenta disco
fsutil file createnew grande_arquivo.txt 1073741824 # Cria arquivo de 1GB

Processos e Serviços

Gerenciamento de Processos

tasklist /svc # Lista processos e serviços
taskkill /IM chrome.exe /F # Força fechar Chrome
wmic process get name,processid,commandline # Lista detalhada

Controle de Serviços

sc queryex type= service state= all # Lista todos serviços
net start # Lista serviços em execução
sc config "servicename" start= delayed-auto # Configura serviço

Utilitários Avançados

Informações do Sistema

systeminfo # Detalhes completos
wmic bios get serialnumber # Número de série da BIOS
powercfg /energy # Diagnóstico de energia

Comandos Úteis

shutdown /r /t 0 # Reinicia o PC
cipher /w:C # Sobrescreve espaço livre
whoami /all # Info do usuário

PowerShell

Administração do Sistema

Get-WindowsUpdateLog # Log de atualizações
Get-Process | Sort-Object CPU -Descending # Processos por CPU
Get-NetTCPConnection -State Established # Conexões ativas

Utilitários PowerShell

Get-ChildItem -Recurse | Measure-Object -Property Length -Sum # Tamanho total
Test-NetConnection google.com -Port 80 # Testa porta
Get-HotFix | Sort-Object InstalledOn -Descending # Updates instalados

Scripts Úteis para Debian

Atualização do Sistema

Atualizar Sistema Completo

sudo apt update && sudo apt upgrade -y
sudo apt update && sudo apt full-upgrade -y
sudo apt autoremove -y && sudo apt autoclean

Gerenciar Repositórios

sudo add-apt-repository ppa:exemplo/ppa -y
sudo add-apt-repository --remove ppa:exemplo/ppa -y
sudo apt edit-sources

Softwares Essenciais

Pacotes Básicos

sudo apt install curl wget git vim htop neofetch -y
sudo apt install build-essential dkms linux-headers-$(uname -r) -y
sudo apt install net-tools software-properties-common apt-transport-https ca-certificates -y

Dev Tools

sudo apt install python3 python3-pip python3-venv -y
sudo apt install nodejs npm -y
sudo apt install default-jdk default-jre maven -y

Manutenção e Otimização

Limpeza de Sistema

sudo apt autoremove --purge -y && sudo apt autoclean
sudo journalctl --vacuum-size=100M
sudo rm -rf ~/.cache/thumbnails/*

Monitoramento

htop
df -h && du -sh /* 2>/dev/null | sort -hr | head -20
free -h && vmstat 2 5

Configuração de Rede

Diagnóstico

ip a && ip r
ping -c 4 google.com
ss -tulpn | grep LISTEN

Firewall (UFW)

sudo ufw enable && sudo ufw default deny incoming
sudo ufw allow 22/tcp && sudo ufw allow 80/tcp
sudo ufw status verbose

Docker e Containers

Instalação do Docker

curl -fsSL https://get.docker.com | sudo bash
sudo usermod -aG docker $USER
sudo systemctl enable docker && sudo systemctl start docker

Docker Compose

sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
docker-compose --version

Script Automático

Script de Configuração Inicial do Debian

#!/bin/bash # Script de configuração inicial do Debian echo "Atualizando sistema..." sudo apt update && sudo apt upgrade -y echo "Instalando pacotes essenciais..." sudo apt install curl wget git vim htop neofetch build-essential -y echo "Configurando firewall..." sudo ufw enable sudo ufw allow 22/tcp sudo ufw allow 80/tcp sudo ufw allow 443/tcp echo "Instalação concluída!" neofetch

Salve como setup.sh, execute chmod +x setup.sh && ./setup.sh
